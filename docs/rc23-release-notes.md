# v3.0.0-rc.23 — 历史记录一致性与安全更新

- 日历和历史列表修改跑步时，使用与常规入口一致的完整记录页，支持里程、用时、配速、心率和备注。
- 更正已有历史记录继续使用原更正事务：保留完成打卡锁定，重新计算长期/阶段目标，保留历史删除入口。
- 归档跑步和早于卡创建日的已有记录可编辑；没有记录时，原有“只补当天原计划”的补打卡规则不变。
- 记账习惯“记一笔”的支出新增“同时添加到额外开支”。首次带入金额、事项、日期和时间，反思由用户继续填写；重复操作不重复创建，也不重复统计收支。收入不提供此选项，没有活动额外开支卡时会提示。
- 修复8.05、0.29、81.01等金额保存反思时的精度误判，不放宽格式及安全整数限制。
- 仅更新开发工具：Vite 8.3.5，Vitest与coverage-v8 4.1.12；React、Router和其他生产依赖不变，数据库与备份格式不变。
