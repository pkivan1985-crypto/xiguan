# v3.0.0-rc.22 — 钱专项

- 新增底部“钱”入口，集中查看月度收入、消费支出、还款及当前确认负债。
- 信用卡、贷款、固定支出支持独立应付日期、月度重复、三类小计和总合计。
- 支持部分/多次付款、历史补录、修改和显式撤销；付清后显示单圆绿色勾，点击查看付款详情。
- 独立记账与原记账/额外开支整合，已有支出可关联账单，不重复复制金额。
- 按账户去重统计确认欠款，不自动将整笔月供当成归还本金。
- 金额两位小数连续输入；事项、分类、账户与备注可查询。
- 普通/加密备份兼容旧数据，新增金额、来源和关联的强校验。

## 验证和边界

本地104个测试文件、525项测试通过；类型检查、生产构建、CSS检查通过，依赖审计0漏洞。浏览器实测付款、纠错、备注搜索及窄屏布局。

手机软键盘、触摸、安全区、冷启动离线和旧版PWA升级仍待Android/iPhone应用反馈。未保存表单请使用页面内返回按钮；系统/浏览器SPA返回手势目前不拦截。用户已知悉边界并确认先发布本RC，再根据使用反馈更新。

本应用只登记已发生的付款，不执行转账，不连接银行；数据保存在本机浏览器。更新前建议导出备份，不要清除网站数据。
