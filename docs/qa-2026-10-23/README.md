# 历史跑步编辑统一与记账带入额外开支：本地修复记录

日期：2026-10-23。基于RC.22，未改版本号、未发布、未更改依赖或数据库/备份schema。

## 局部修改

- 进展月历、历史列表的跑步修改均进入既有跑步记录页，保留里程、用时、分段配速、心率和备注输入。
- 已有历史跑步保存复用原 `correctActionRecord` 更正事务，保留完成打卡锁定，但重新计算长期/阶段目标完成或回退；历史页提供原有删除能力，须用户点击确认。
- 保存或关闭历史记录后返回对应日期进展页。
- 记录页读取传入单卡 `recordCardId`：仅当该日期已有记录时，可打开归档跑步及早于卡创建日的有效记录。普通今天页和补打卡默认筛选不改变，不使归档卡重新出现。
- 记账习惯的“记一笔”支出表单新增默认不勾选的“同时添加到额外开支”。收入不提供此选项。
- 勾选时在同一事务内保存记账，并向已有活动额外开支卡追加基础信息；没有活动额外开支卡则提示，整次回滚，不自动新建习惯。
- 额外开支使用稳定来源条目ID，重复提交不重复新增，不覆盖已填写反思。没有购买原因时明确显示“待填写购买原因”；余额/赚回天数/补偿留空，支出性质暂用“可延后”，用户可编辑。
- 这是首次带入，不是双向同步；后续反思独立编辑。钱专项以原记账事实计数，关联的反思副本不重复记入收支。
- 修复阻断反思保存的既有小数换算缺陷：十进制整数精确缩放，8.05等金额不会因浮点乘法被误判为非整数分；不放宽格式、小数位、正数、阈值或安全整数限制。
